# study-log

2026-2학기 컴퓨터공학과 학습 기록 저장소.
매일 조금씩, 부담 없이 남기는 것을 목표로 함.

## 폴더 구조
study-log/
├── logs/ 일일 학습 로그 (YYYY-MM-DD.md)
├── projects/ 진행 중인 프로젝트 (프로젝트별 폴더)
└── README.md 이 파일 (개요 + 주간 회고 누적)

## 로그 작성 규칙

- 파일명: `YYYY-MM-DD.md` (예: `2026-08-24.md`) — 이 형식만 사용
- 내용은 아래 템플릿 3줄.

```md
## YYYY-MM-DD

### 한 일
-

### 막힌 점
-

### 내일
-
```

## 프로젝트 폴더 규칙

- 폴더명: 영문 소문자 + kebab-case (예: `db-erd-tool`, `react-schedule-app`)
- 한글 폴더명/파일명 사용하지 않음
- 각 프로젝트 폴더 안에 별도 `README.md`로 개요/진행상황 관리

## 커밋 메시지 규칙

| 접두어 | 용도 |
|---|---|
| `feat :` | 기능 추가 |
| `fix :` | 버그 수정 |
| `docs :` | 문서/로그 작성 |
| `refactor :` | 구조 변경 |

예: `docs: 08-24 로그 추가`, `feat : ERD 초안 작성`

## 체크인

매주 금요일, 그 주 커밋/로그를 들고 회고 및 다음 방향 정리.
(상황에 따라 유동적으로 조정)
